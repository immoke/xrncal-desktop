# xrncal Desktop 1.2.0.4

本版新增群晖任务管理，并修复群晖删除后重新导入同名日历时，客户端仍显示旧条目的问题。

## 群晖任务

- 点击左上角的工作区入口，在「日历」和「任务」之间切换。侧栏可用「<<」和「>>」收起或展开。任务侧栏上方是日期选择，下方是分类，可按到期日和分类筛选。
- 日历和任务各自配置服务器。切到「任务」后，使用群晖 Calendar 的 CalDAV 地址和账号添加任务服务器。可配置多个群晖服务器，并同步全部或指定一台。
- 读取群晖已有的任务清单。逾期任务继续显示在「待办」中，直到完成。勾选完成或恢复待办时，状态会写回群晖，客户端分别在「待办」和「已完成」中显示。
- 支持新建、改名、修改颜色和删除可编辑的任务分类。修复分类操作返回群晖 `9009` 的参数编码问题。

## 日历同步

- 每次同步按 CalDAV 地址核对日历。服务器确认旧地址已删除后，客户端会从列表移除旧条目，同名的新日历继续同步。旧日历的本地缓存会保留。
- 独立添加的在线 ICS 订阅仍可在「管理订阅」中单独取消。

## 下载与升级

- 提供 Windows x64 安装版、绿色 ZIP 和 Linux x64 AppImage。绿色版解压后运行 `xrncal.exe`。覆盖升级前退出程序，并保留原目录中的 `xrncal.sqlite`。

## English

This release adds Synology task management and fixes stale calendar entries after a calendar is deleted and imported again under the same name.

### Synology tasks

- Switch between **Calendar** and **Tasks** from the top-left workspace menu. Use **<<** and **>>** to collapse or expand the sidebar. The Tasks sidebar lets you filter by due date and category.
- Set up calendar accounts and task servers independently. Add a task server with the Synology Calendar CalDAV URL and sign-in. Refresh all configured task servers or select one to sync.
- Read existing task lists from Synology. Overdue tasks remain in **To do** until completed. Completing or reopening a task writes its status back to Synology and moves it between **To do** and **Completed**.
- Create, rename, recolor, and delete editable task categories. Fixed the request encoding that caused Synology error `9009` during category operations.

### Calendar sync

- Sync matches calendars by their CalDAV address. Once the server confirms that the old address has been deleted, the stale entry leaves the list and the new calendar with the same name continues syncing. The old calendar's local cache is retained.
- Remove independently configured ICS feeds from **Manage subscriptions**.

### Downloads and upgrade

- Available as a Windows x64 installer, a Windows x64 portable ZIP, and a Linux x64 AppImage. To use the portable ZIP, extract it and run `xrncal.exe`. Quit the app before upgrading in place and keep the existing `xrncal.sqlite`.
